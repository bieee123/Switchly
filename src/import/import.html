This file contains login cookies and site storage. Anyone with the file can access your accounts. Only import files you exported yourself.

    How import works

    • Sessions with the same ID are replaced; new sessions are added.
    • Existing sessions are never deleted by an import.
    • Duplicate order numbers are allowed and sorted by creation time.
    • Imported cookies are not validated against the remote website.

    Some websites bind logins to a device, IP address, or browser fingerprint, so an imported session may not work everywhere.
